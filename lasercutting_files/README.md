# lasercutting_files/

Enclosure/mirror lasercutting sources for the sensor module and the two-way
acrylic mirror front.

- `designing_cuts_acrylic_plates.f3d` — Autodesk Fusion 360 design file (the
  editable source of all cuts).
- `testcuts_radarsensors.dxf` — test cuts, for an acrylic plate of 225×400 mm.
- `finalcut_rounded_rectangle.dxf` — the final cut, for an acrylic plate of
  250×300 mm.

View DXF files without CAD software at <https://dxfviewer.app/>.
