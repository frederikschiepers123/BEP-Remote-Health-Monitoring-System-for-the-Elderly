- "designing_cuts_acrylic_plates.f3d" is the AutoDesk Fusion file which contains the design of the different cuts
- "testcuts_radarsensors.dxf" is the dxf file used to make the test cuts on an acrylic plate of 225x400mm. 
- "finalcut_rounded_rectangle.dxf" is the dxf file used to make the final cut on an acrylic plate of 250x300mm.


You can easily view the dxf files via the following website: https://dxfviewer.app/
