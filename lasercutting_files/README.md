# lasercutting_files/

Enclosure/mirror lasercutting sources for the sensor module and the two-way
acrylic mirror front.

- `designing_cuts_acrylic_plates.f3d` — Fusion 360 design file (the editable
  source).
- `finalcut_rounded_rectangle.dxf` — the final production cut.
- `testcuts_radarsensors.dxf` — earlier test cuts for the radar apertures.

View DXF files without CAD software at <https://dxfviewer.app/>.
