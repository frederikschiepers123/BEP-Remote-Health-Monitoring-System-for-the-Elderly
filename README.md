# Remote Health Monitoring System for the Elderly
This folder contains all relevant documents for the bachelor project called "Remote Health Monitoring System for the Elderly".

### This folder contains the following:
- `./HealthMonitorWakeTest:` A folder containing an Android Studio project, to design an application which turns a screen on or off based on MQTT messages.
- `./MagicMirror:` A folder containing the software for the UI, based on the open-source MagicMirror² platform
- `./PCB:` Contains all KiCad files for the PCB design (and some testing results)
- `./Readout Code HMMD-MR60BHA2 and BMP:` Here you find code to read from the mmwave radar sensors with filtering implemented. Additionally code to readout the BMP sensor is also included hier.
- `./apk:` Contains the apk file which installs the Android application "HealthMonitorWakeTest.
- `./documents_and_diagrams:` A folder containing several diagrams as well as an assortment of documents (such as the thesis report and the thesis presentation)
- `./fully:` A folder containing a configuration file for the application "Fully Kiosk Browser"
- `./lasercutting_files:` Design files used to cut the acrylic plates
- `./papers:` A folder containing all papers and references used in the project
